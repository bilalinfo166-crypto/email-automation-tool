How to add a sender account?
OAuth (easy)
App password
  1. Choose OAuth below, then click Continue with Google.
  2. A Google window opens — pick the mailbox you want to connect (it must be on your sending domain).
  3. Click Allow to let Warmwire send emails and run warmup from that inbox.
  4. You're connected. Your password is never stored, and you can disconnect anytime from your Google Account.
  1. On that Google account, turn on 2-Step Verification — app passwords need it to work.
  2. Go to myaccount.google.com/apppasswords.
  3. Create an app password for Mail. Google shows you a 16-character code (like abcd efgh ijkl mnop).
  4. Enter your email and paste that code below. Leave SMTP as smtp.gmail.com, port 587.
  5. Keep the code private — you can delete it anytime from the same Google page.
